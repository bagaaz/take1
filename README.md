# Take 1 Comunicação

Site institucional estático da Take 1 Comunicação. Apresenta a agência, seus serviços, clientes e canais de contato.

## Visualizar localmente

Com Python 3 instalado, execute na raiz do repositório.

```bash
python3 -m http.server 8000 --directory public
```

Abra [localhost:8000](http://localhost:8000). Use HTTP para que o JavaScript consiga carregar os componentes compartilhados do site. Veja a [documentação completa](public/README.md).
